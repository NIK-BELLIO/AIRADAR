AI Radar API

Make, edit and render short videos from your own system: a script into a video, a talking video into an edited reel with captions and music, photos into a narrated video, and thumbnails - delivered as MP4 and image files.

Base URL https://airadar.me/api/v1 · JSON in, JSON out · one key per account.

Quick start

  1. Sign in to AI Radar, open Dashboard → Connect your AI and create a key. It starts with arx_ and is shown once.
  2. Check it:
    curl -X GET https://airadar.me/api/v1/me \
  -H "Authorization: Bearer $AIRADAR_KEY"
  3. Edit a video, then render it and download the MP4:
    curl -X POST https://airadar.me/api/v1/edits \
  -H "Authorization: Bearer $AIRADAR_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "video_url": "https://example.com/talk.mp4", "style": "pro-viral" }'

# data.id in the answer is the video id
curl -X POST https://airadar.me/api/v1/videos/{id}/render \
  -H "Authorization: Bearer $AIRADAR_KEY"

# poll until data.state is done (usually one to four minutes)
curl -X GET https://airadar.me/api/v1/videos/{id}/render \
  -H "Authorization: Bearer $AIRADAR_KEY"

curl -L -o video.mp4 https://airadar.me/api/v1/videos/{id}/file \
  -H "Authorization: Bearer $AIRADAR_KEY"

Keys and answers

Send the key on every request as Authorization: Bearer arx_.... Keys are made and revoked in the Dashboard; an account can hold five.

Every answer is JSON. A success is { "ok": true, "message": "...", "data": { ... } }; anything else is { "ok": false, "error": "..." } with the HTTP status below. Requests are checked before anything runs: an unknown field, a wrong type or a value outside the allowed list is a 400 that names the field.

{
  "ok": true,
  "message": "The edit is ready to open: https://airadar.me/studio/?deck=deck_0902...",
  "data": { "id": "deck_0902...", "video_id": "deck_0902...", "url": "https://airadar.me/studio/?deck=deck_0902...", "started": true, "clips": 1 }
}

Getting the MP4

Every create call answers at once with an id and a studio link (the same video, editable in the browser). To get the file without a browser, render it on AI Radar's servers:

EndpointWhat it does
POST/api/v1/videos/{id}/renderStart the render. Answers at once; the video is made on AI Radar's servers.
GET/api/v1/videos/{id}/renderWhere it has got to: data.state is not_started, queued, rendering, done or failed. When done, data.file_url is the MP4 (thumbnails: data.images).
GET/api/v1/videos/{id}/fileThe finished MP4, with your key. Byte ranges are supported.

A render takes about as long as the video plus the build: roughly one minute for a 20-second script video, up to four for an edit of a 40-second talk. Poll every 10 to 20 seconds. Thumbnails come back as a list of image links in data.images.

Make a video from a script

POST/api/v1/videos

Send a script (intro, 2 to 10 scenes, outro) and AI Radar builds a vertical video around it: footage, captions, motion and music. GET /api/v1/video-guide returns the exact script shape and the rules for writing it.

Body

FieldTypeWhat it does
script requiredobjectThe script object: title, subtitle, kicker, intro, sections[], outro.
stylestringfootage (default), editorial or motion_graphic
footage editorial motion_graphic
aspectstringDefault 9:16
9:16 16:9 1:1 4:5
templatestringOptional look for the whole video; see list_templates
maison noir ivory editorial warm neon ocean sunset mono forest platinum champagne obsidian porcelain midnight marble emerald sand ruby slate amber frost rosegold
fontstringOptional headline font for the whole video. A scene can override it with look.font.
archivo space-grotesk alice viaoda inter georgia prata manrope jetbrains-mono
lookstringOptional motion-design look instead of footage: the spoken words become kinetic typography, each scene gets a self-drawing icon, shape transitions and cuts on the music's beat. kinetic (bold type, cream + yellow), neon (dark tech glow), minimal (clean white + blue), news (navy + red), paper (hand-made paper craft), luxe (black + champagne serif). Leave it out for real footage.
kinetic neon minimal news paper luxe

Example

curl -X POST https://airadar.me/api/v1/videos \
  -H "Authorization: Bearer $AIRADAR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "script": {
    "title": "Why rents keep rising",
    "language": "en",
    "intro": { "main": "Rents are up again", "narration": "Rents rose for the ninth month running." },
    "sections": [
      { "type": "text", "headline": "Supply is the problem", "narration": "Cities are building half the homes they need." }
    ],
    "outro": { "main": "Follow for more", "narration": "Follow for the next one." }
  },
  "aspect": "9:16"
}'

Change the text or footage of a finished video

Send a finished video and the texts or shots to change. The design, timing and music stay; only what you name changes.

Body

FieldTypeWhat it does
video_urlstringPublic https link to the finished video, up to 24 MB
textsarray of objectsTexts to change (up to 30)
footagearray of objectsFootage areas to change (up to 8)
notestringOptional one line shown to the user when the link opens

Example

curl -X POST https://airadar.me/api/v1/swaps \
  -H "Authorization: Bearer $AIRADAR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "video_url": "https://example.com/finished.mp4",
  "texts": [ { "find": "SUMMER SALE", "replace": "WINTER SALE" } ]
}'

Thumbnail from a video

POST/api/v1/thumbnails/from-video

Send a video: AI Radar picks the best frames, takes the video's own text off them, cuts the person out and sets your title on it.

Body

FieldTypeWhat it does
video_urlstringPublic https link to the video, up to 24 MB
textstringOptional: the words on the thumbnail, 2 to 6 punchy words in the user's language. Leave out to write them from what is said in the video.
templatestringDefault cutout (the person cut out beside big words)
cutout pop arrowpro behind docu tech podcast breaking money extrude glass burst magazine neon echo bold band center sidebar minimal stamp versus beforeafter arrow number
sizesarray of stringse.g. ["1280x720"] for YouTube, 1080x1920 vertical, 1080x1080 square. Default 1280x720.
variationsnumber1 to 3, each from a different frame (default 1)
remove_textbooleanTake the text already on the video off the frame (default true)
notestringOptional one line shown to the user when the link opens

Example

curl -X POST https://airadar.me/api/v1/thumbnails/from-video \
  -H "Authorization: Bearer $AIRADAR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "video_url": "https://example.com/talk.mp4",
  "text": "How I doubled my sales",
  "sizes": ["1280x720"]

Guide and templates

GET /api/v1/video-guide returns the script shape for /videos and how to write each scene. GET /api/v1/templates lists the template ids and fonts. The 33 caption looks for /edits and /photo-videos are the values of style:

pro-suite pro-trust pro-walk pro-focus pro-podcast pro-vlog pro-reveal pro-serif pro-yellowcaps pro-street pro-block3d pro-doodle pro-lime pro-listing pro-agent pro-cyan pro-yellow pro-pill pro-goldpro pro-stack pro-viral pro-punch pro-karaoke pro-clean pro-neon pro-luxe pro-pop pro-glow pro-gold pro-highlight pro-vivid pro-editorial pro-comic pro-hollow pro-minimal pro-marker classic

Errors and limits

StatusMeaning
400The request is wrong: a missing or unknown field, a wrong type, a value not in the list, or a link that could not be fetched. error says which.
401No key, or a key that was revoked.
404No such endpoint, or no video with that id on this account.
409The video is not rendered yet.
503Server rendering is not available right now; try again later.
500Something failed on AI Radar's side.

Limits

  • 40 videos per account per day (all create endpoints together).
  • Videos up to 24 MB each, up to 12 minutes; images up to 12 MB (JPEG, PNG, WebP, GIF). Links must be public https addresses; Google Drive and Dropbox share links work.
  • Uploaded files are kept for two days; rendered thumbnails for a week; rendered MP4s stay in the account's library.
